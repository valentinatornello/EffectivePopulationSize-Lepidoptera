# Effective Population Size (Ne) -Lepidoptera 

An open-source R toolkit for effective population size (Ne) estimation in laboratory-reared Lepidoptera populations.

## Objectives

- Estimate demographic Ne
- Estimate sex-ratio Ne
- Estimate harmonic mean Ne across generations
- Evaluate population bottlenecks
- Monitor genetic risk in insectary colonies
- Generate reproducible reports

## Applications

- Diatraea saccharalis
- Spodoptera frugiperda
- Anticarsia gemmatalis
- Helicoverpa zea
- Rachiplusia nu
- Other Lepidoptera species

## Methods

The repository includes:

- Sex-ratio Ne
- Harmonic mean Ne
- Variance effective size
- Survival analysis
- Population monitoring
- Genetic diversity metrics
